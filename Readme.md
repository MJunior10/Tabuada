🧠 Memory & Quiz App

Aplicação web interativa para memorização + quiz automático, com sistema de pontuação, responsiva para desktop e mobile.

📌 Sobre o Projeto

O Memory & Quiz App foi desenvolvido para permitir que o usuário:

📖 Memorize conteúdos (modo estudo)

🧠 Faça um quiz automático após a memorização

📊 Receba pontuação baseada nas respostas

📱 Utilize tanto no computador quanto no celular (100% responsivo)

🚀 Funcionalidades

✅ Sistema de memorização por etapas

✅ Quiz automático após finalizar a memorização

✅ Sistema de pontuação funcional

✅ Feedback visual de acertos e erros

✅ Layout moderno e minimalista

✅ Design responsivo (Mobile First)

✅ Interface leve e rápida (HTML + CSS + JS puro)

📱 Responsividade

▶️ Como Executar
Opção 1 – Abrir localmente

Baixe o projeto

Abra o arquivo index.html no navegador

Opção 2 – Usar com servidor local (recomendado)

Se você tiver o VS Code:

Instale a extensão Live Server

Clique com botão direito em index.html

Selecione Open with Live Server

🎯 Fluxo da Aplicação

Usuário inicia modo memorização

Após finalizar, o quiz inicia automaticamente

Pontuação é calculada

Resultado final exibido na tela

📊 Sistema de Pontuação

+1 ponto por resposta correta

Resultado exibido ao final

Reinício automático disponível
